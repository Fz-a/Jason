# Techfolio — 配色说明

与 [brittnevaldivia.com](https://brittnevaldivia.com/) 模板默认配色一致：

| 名称 | HEX | 用途 |
|------|-----|------|
| **奶油底** | `#F7F1E8` | 页面主背景 |
| **深绿** | `#043439` | 实心按钮 |
| **森林绿** | `#0F4C45` | 导航、描边、强调 |
| **墨绿** | `#162B26` | 主标题 |
| **浅绿区块** | `#DDE7DE` | About / Projects 等区块 |
| **正文灰绿** | `#3E514D` | 段落说明 |
| **次要灰** | `#6B7B77` | 页脚、辅助文字 |

## 本地运行

```bash
pnpm dev
```

打开 http://localhost:4321
